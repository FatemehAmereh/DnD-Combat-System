This is an Unreal Engine 5.3 project that aims to implement a DnD combat system similar to the one in Baldur's Gate 3. The work was done as part of a Master's thesis available [here](https://aaltodoc.aalto.fi/items/20f87aef-461d-4358-bef4-6bc436f4131f).<br /><br />
The project uses both C++ and Blueprints to implement the combat system. It also takes advantage of the Gameplay Ability system (GAS) framework to define certain concepts, such as abilities and attributes.
